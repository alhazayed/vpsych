# Educational Model — Stage 9 Supervisor

**Audience:** Psychiatric educators, program directors, board examiners (educational use)

## What Supervisor teaches

Supervisor AI evaluates **therapist process** after a completed SP session:

1. Skill scoring with cited turns  
2. Modality recognition (what actually occurred — never forced)  
3. Banded feedback (beginner → board)  
4. Reflective practice (questions, bias, countertransference reminders, uncertainty)  
5. Portfolio + certification progress (conservative thresholds)

## What Supervisor does not do

- Does not treat or diagnose real patients  
- Does not modify the simulated patient’s cognition, emotion, memory, or adaptation  
- Does not replace Stage 7 Education or Stage 8 Validation  
- Does not claim validated competency instruments  

## Feedback bands

| Band | Intent |
|------|--------|
| Beginner | Open questions, reflections, basic safety |
| Intermediate | Differentials from case evidence; agenda + validation |
| Advanced | Formulation + modality-congruent plans; rupture repair |
| Consultant | Model flexible recognition; coach juniors |
| Board | Consistent safety, ethics, formulation; reflective discipline |

## Outcomes framing

Use Supervisor outputs for formative coaching and portfolio review. Do **not** present scores as OSCE gold standards or licensure readiness without independent human examination.
