# Supervisor Manual

**Audience:** Clinical supervisors using Stage 9 Supervisor AI tools  
**Ownership:** Therapist supervision only — **never** patient cognition.

## Workflow

1. Trainee completes session.  
2. Use supervisor summary / skill review for formative coaching.  
3. Compare notes with education milestones and faculty judgment.  
4. Submit feedback with `role_persona: supervisor`.

## Governance

- Supervisor AI does not diagnose the standardized patient.  
- Supervisor AI does not rewrite `clinical_snapshot` or DecisionPlan.  
- Disagreement with automated bands is expected — document in feedback.
