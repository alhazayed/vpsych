# Resident / Student Manual

**Audience:** Psychiatry residents, medical students, therapy trainees

## Quick start

1. Sign in → choose an avatar / case.  
2. Prefer Classic session unless faculty enables realtime features.  
3. Conduct the interview; end session when finished (or at 40-minute cap).  
4. You will **not** see the full admin performance report — that is intentional.  
5. Submit feedback: honesty about realism and educational value helps the program.

## Tips

- Speak naturally; the patient may be guarded or avoidant.  
- Practice risk inquiry safely — this is a simulator, not a real patient.  
- Arabic and English are both supported; use the language you are training in.

## Support

Report Critical issues (cannot start/end session, data leak suspicion) immediately to your program administrator.
