# Institutional Feedback Program

**In-app:** `/feedback` · `/admin/feedback`  
**Guide:** `../cidp/FEEDBACK_MANAGEMENT.md`  
**Schema:** `institutional_feedback` (+ owner, resolution, audit trail)

## Roles

Residents · Faculty · Clinical Supervisors · Researchers · Hospital Administration · IT Teams

## Required submission fields

Institution · Role · Version · Category · Severity · Priority · Status · Owner · Resolution · Root Cause · Lessons Learned · Audit Trail

## Severity classification

Critical · High · Medium · Low · Suggestion

Open **Critical** feedback blocks GA gate `no_unresolved_critical_findings` until resolved / wont_fix / duplicate.
