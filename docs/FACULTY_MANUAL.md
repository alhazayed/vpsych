# Faculty Manual

**Audience:** Course directors, clerkship / residency faculty  
**Version:** VPsych 1.0 RC1 Controlled Institutional Deployment

## What VPsych is

A bilingual (EN/AR) therapist-training platform with AI standardized patients and **admin-only** performance reports. Patients are fictional.

## Teaching workflow

1. Assign a case / avatar appropriate to training level.  
2. Resident completes a voice or text session (≤ 40 minutes).  
3. Review admin report + supervisor tools for formative discussion.  
4. Collect faculty feedback (`role_persona: faculty`) after observed sessions.

## Do / Don't

| Do | Don't |
|----|-------|
| Treat scores as formative | Use scores for high-stakes credentialing |
| Discuss alliance & risk skills | Claim validated psychometrics |
| File Critical defects immediately | Modify patient engines |

See `KNOWN_LIMITATIONS.md` and `FEEDBACK_GUIDE.md`.
